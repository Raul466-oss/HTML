Preguntas Frecuentes sobre HTML5

¿Que es un elemento semantico?

Es una etiqueta que describe claramente el significado y tipo de contenido que alberga para el navegador y los buscadores.

¿Cual es la funcion del elemento main?

Define el bloque de contenido central y principal de la pagina. Solo debe incluirse uno por documento.

¿Para que se utilizan las etiquetas details y summary?

Permiten crear apartados desplegables nativos donde el texto dentro de summary actua como boton para mostrar u ocultar el contenido.
